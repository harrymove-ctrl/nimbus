Nimbus02 · The crew
You set the goal. It plans.

One row per agent. They work at the same time.

The Orchestrator drafts the plan on Ultra. You reword, reorder or approve. Then every agent gets a lane, with its model, its tokens and its cost on the row.

  • Ultraplans the run and reviews the result
  • Superresearches, analyses, writes
  • Nanochecks the output and writes the memories

Nimbus05 · Rules and memory

An approval becomes a rule. Then it learns.

The rule is one line in the workstream's SKILL.md, revocable with one click. After the run, Nano writes memories and rewrites the how-to.

Nimbus07 · How it uses Nebius
Three sizes, one endpoint

Priced per step. The bill is on screen.

A classifier routes every hop to the cheapest Nemotron that can do it, and shows the saving against sending everything to Ultra. Every call goes to api.tokenfactory.nebius.com.
