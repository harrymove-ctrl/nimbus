What Real Models Taught Us Beyond the Mock

Six live recording attempts ($0.49 total) exposed 7 real agent lessons.

01 · Nano 30B Thinking Budget
690 → 102 tok

With <think> on, Nano 30B spent its whole 1,500-token ceiling thinking and never called save_learning. Setting enable_thinking: false made it 6× smaller and 100% reliable.

Commit 23f32be
02 · Turn Budget & Synthesis
12 Turns + Report

The Researcher read one file per turn and exited at turn 8 with no report. Raising the budget to 12 with a tool-free final turn guaranteed a synthesis every run.

Commit be3ddc0
03 · Automatic Bus Handoffs
0 Re-reads

Ultra wrote "(include the report)" instead of pasting it, forcing the Writer to re-read every raw file. The runtime bus now attaches prior crew reports automatically.

Commit 3e117e6
04 · Rule Key Normalization
100% Policy Match

Normalizing { to, body } and { channel, text } across roles ensured saved allow: rules in SKILL.md matched on Run 2 with zero friction.
