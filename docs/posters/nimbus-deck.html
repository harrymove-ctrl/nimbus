What real models taught us beyond the mock

198 live Nebius Token Factory calls ($0.49 total) exposed 7 real agent lessons.

01 · Nano 30B Thinking Toggle690 → 102 tok

With <think> on, Nano 30B spent its whole 1,500-token ceiling thinking and never called save_learning. Setting enable_thinking: false made it 6× smaller and 100% reliable.

Commit 23f32be
02 · Turn Budget & Synthesis12 Turns + Report

The Researcher read one file per turn and exited at turn 8 with no report. Raising the budget to 12 with a tool-free final synthesis turn guaranteed a summary every run.

Commit be3ddc0
03 · Automatic Bus Handoffs0 File Re-reads

Ultra wrote "(include the report)" instead of pasting it, forcing the Writer to re-read every raw file. The runtime bus now attaches prior crew reports automatically.

Commit 3e117e6
04 · Rule Key Normalization100% Rule Match

Normalizing { to, body } and { channel, text } across roles ensured saved allow: rules in SKILL.md matched automatically on Run 2 with zero friction.
