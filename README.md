# Nimbus

A glowing cloud that runs your ongoing work with a crew of NVIDIA Nemotron
agents, asks before it acts, and learns from every run.

Built for the Nebius x NVIDIA Global AI Hackathon (Personal AI track) on
Nebius Token Factory with Nemotron 3 Ultra, Super and Nano.

Status: planning complete, build in progress. See `docs/PLAN.md`.

## Setup

```bash
pnpm install
cp .env.example .env.local   # fill NEBIUS_API_KEY and TAVILY_API_KEY
pnpm dev
```
